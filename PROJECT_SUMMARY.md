# Project Summary

## Indian Language Text Normalization + SSML Rule Generator for TTS

A complete, production-ready framework for normalizing text in Indian languages for Text-to-Speech systems.

## ✅ Completed Features

### Backend (Python FastAPI)
- ✅ Complete normalization pipeline
- ✅ Rule engine with YAML-based configuration
- ✅ DFA-based pattern matching engine
- ✅ Specialized normalizers for:
  - Cardinal numbers
  - Ordinal numbers
  - Currency (₹)
  - Dates (DD/MM/YYYY)
  - Time (HH:MM AM/PM)
  - Units (kg, km, m, cm, l, ml)
  - Abbreviations (Dr., Mr., Mrs., etc.)
- ✅ SSML generator for TTS output
- ✅ RESTful API endpoints
- ✅ Comprehensive error handling
- ✅ CORS configuration

## How to Run

1. **Start the application:**
   ```bash
   docker-compose up
   ```

2. **Access services:**
   - Frontend: http://localhost:3000
   - Backend API: http://localhost:8000
   - API Docs: http://localhost:8000/docs

3. **Test normalization:**
   - Use the web UI at http://localhost:3000
   - Or use the API directly (see README.md)

## Key Technologies

- **Backend**: Python 3.11, FastAPI, PyYAML
- **Frontend**: React 18, Tailwind CSS, Axios
- **Containerization**: Docker, Docker Compose
- **Testing**: pytest

## Next Steps for Extension

To add a new Indian language (e.g., Telugu `te-IN`):

1. Copy `backend/locales/hi-IN.yml` to `backend/locales/te-IN.yml`
2. Translate all rule mappings to Telugu
3. Test with sample sentences
4. Restart the service

The system automatically detects and loads the new locale!
